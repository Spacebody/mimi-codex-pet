# Mimi V1

Mimi V1 is the original Codex pet package.

- Atlas: `pet/spritesheet.webp`
- Size: 1536×1872 (8 columns × 9 rows)
- Cell size: 192×208
- Manifest: `pet/pet.json`
- Contract: legacy pet manifest without `spriteVersionNumber`

The `qa/` and `source/` directories are the original V1 validation and generation artifacts. They remain physically isolated from V2.

Install V1 from the repository root:

```bash
./install.sh --version v1
```
